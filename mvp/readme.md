# MVP – Prototype Fonctionnel

Ce dossier contient le **MVP (Minimum Viable Product)** du projet.  
Il regroupe les écrans, interfaces et parcours développés sous forme de pages HTML/CSS afin de présenter une première version fonctionnelle de l’application.

L’objectif du MVP est de tester les principales fonctionnalités, l’ergonomie et l’expérience utilisateur avant un développement plus avancé.

---

## Objectifs du MVP

- Visualiser les parcours utilisateurs principaux.
- Tester l’interface et la navigation.
- Simuler les fonctionnalités clés.
- Servir de support pour les tests utilisateurs et le feedback.

---

## Organisation du dossier

Chaque sous-dossier correspond au travail d’un membre de l’équipe ou à un ensemble de pages spécifiques.

- **gautier/**  
  Contient les pages de connexion, inscription, home, publicité, live session et paramètres.

- **mathias/**  
  Contient les pages de messages et de récompenses.

- **pierre/**  
  Contient les pages de profil, abonnements et reels (vidéos).

- **thersan/**  
  Contient la page événement.

Chaque page est composée principalement de fichiers :
- `.html` pour la structure,
- `.css` pour le style,
- parfois `.js` pour les interactions,
- et des dossiers `Assets`, `icons`, `photos`, `videos` pour les ressources.

---

## Utilisation

Pour visualiser le MVP :

1. Ouvrir un fichier `.html` dans un navigateur.
2. Naviguer entre les pages manuellement ou via les liens intégrés.
3. Tester les parcours proposés.

Aucun serveur n’est nécessaire, tout fonctionne en local.

---

## Remarques

Ce MVP est une version prototype :
- certaines fonctionnalités sont simulées,
- il n’y a pas encore de backend,
- l’objectif principal est l’UX/UI et le parcours utilisateur.

---

## Équipe

Projet réalisé dans un cadre pédagogique pour concevoir et tester une application à travers un MVP interactif.
