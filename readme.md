# Projet – Product Design & MVP

Ce dépôt contient tout le projet : la phase de **design** et le **MVP**.  
Le projet est organisé en deux dossiers principaux : `docs` et `mvp`.

-----

## 📁 Structure du projet

~~~text
.
├── docs/
│   Toutes les étapes de la Phase 1 – Product Design.
│
├── mvp/
│   Le Minimum Viable Product basé sur ce qu’on a défini dans `docs`.
│
└── README.md
~~~

---

## 📂 docs/

Le dossier `docs` contient tout le travail de **conception produit**.  
On y retrouve par exemple :
- la recherche utilisateur et marché,
- les personas,
- les parcours utilisateurs,
- les wireframes et mockups,
- le prototype interactif,
- les tests et retours utilisateurs,
- la priorisation,
- le pitch final.

Chaque sous-dossier a son propre `README.md` qui explique ce qu’il contient et les livrables associés.

---

## 🚀 mvp/

Le dossier `mvp` contient le **prototype fonctionnel / MVP**.  
C’est la partie qu’on peut tester pour voir si notre idée marche vraiment.  
On s’en sert pour :
- valider les hypothèses du produit,
- tester les fonctionnalités de base,
- préparer les prochaines améliorations.

---

## 🎯 Objectif

L’idée du projet, c’est de montrer tout le **processus de conception** puis de passer à un **prototype concret** qu’on peut tester.  
Ça permet de relier la réflexion produit à quelque chose de réel qu’on peut montrer et améliorer.
