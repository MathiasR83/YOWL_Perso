# Product Design

Ce dossier regroupe l’ensemble des étapes – Product Design du projet YOWL.
Il présente le processus de recherche d'un problème corant sur les réseaux sociaux

---

## 🧠 Présentation du projet

YOWL est une application web développée dans le cadre d’un projet Epitech.

L’objectif du projet est de repenser la publicité numérique en la rendant volontaire :
l’utilisateur choisit d’interagir avec des contenus publicitaires en échange de récompenses, tout en supprimant les publicités intrusives imposées.

Le projet s’adresse à tous les utilisateurs, dans une logique d’accessibilité et de simplicité.

## 🎯 Objectifs

Comprendre les usages et frustrations liés à la publicité en ligne

Concevoir une expérience utilisateur centrée sur le consentement publicitaire

Explorer différentes pistes de solutions via le design

Proposer un prototype interactif illustrant le concept YOWL

Il s’agit d’une phase itérative, avec un design volontairement simpliste, pensé pour être amélioré lors des phases suivantes.

---

## 🛠️ Technologies & outils utilisés

### Frontend

HTML / CSS & prototypage

- Choisis pour leur simplicité, leur accessibilité et leur rapidité de mise en place

- Adaptés à une phase de maquettage "fonctionnel" sans logique métier complexe

### Backend

Aucun

Le projet se concentre volontairement sur l’UX/UI et la validation du concept

Design & prototypage

Figma

Conception parcours utilisateurs

Référence principale pour la cohérence visuelle et l’expérience utilisateur

Outils complémentaires

Git & GitHub : versioning et collaboration

VS Code : développement

Trello : organisation des tâches et suivi du projet

---

### ▶️ Installation & lancement du projet

Aucune installation n’est nécessaire.

Le projet correspond à une maquette interactive HTML/CSS, déjà déployée en ligne.

Il est possible d’ouvrir directement les fichiers HTML dans un navigateur depuis le dépôt Git.

Le projet est déployé sur un serveur Apache

### 🧩 Justification des choix techniques

Les choix techniques ont été guidés par le contexte scolaire et les objectifs de la phase :

HTML/CSS permettent de matérialiser rapidement les intentions UX sans complexité technique inutile

Figma est un standard du design produit, facilitant la réflexion, l’itération et la présentation

Netlify offre une solution simple et efficace pour rendre la maquette accessible et testable

L’absence de backend est assumée, la priorité étant donnée à la conception de l’expérience utilisateur

Ces choix garantissent une base claire, compréhensible et évolutive pour les prochaines phases du projet.
