## 1. Main User Flow
1. D’abord, l’utilisateur tombe sur un tutoriel.
2. Dans un second temps, il crée un compte et se connecte.
3. Une fois connecté, il se retrouve sur la page #Home.
4. Il découvre les différentes pages (elles lui sont familières).
5. Il veut gagner des récompenses et accéder à des événements. Il regarde les pubs, puis décide de passer premium.
