# Protocole de Test

Pour rédiger ce README, nous avons recueilli différentes informations (données) auprès de nos camarades de classe.
Nous avons testé uniquement **l’onglet "Pubs"** de notre maquette afin de recueillir les avis des utilisateurs.

---

## Méthodologie

Nous avons d’abord réalisé nous-mêmes cette phase d’observation pour formuler des questions pertinentes.

Ensuite, nous avons posé les questions suivantes à 4 camarades (Loïc, Mattéo, Célia, Lila) :
- Que pensez-vous de ces fonctionnalités ?
- Le système de récompense basé sur le nombre de publicités regardées vous plaît-il ?
- Qu’amélioreriez-vous dans cette rubrique ?
- Quels problèmes avez-vous rencontrés ?

Les réponses ont été **recueillies sur papier** (voir *photo 1*), puis retranscrites dans le tableau ci-dessous.

### **Améliorations apportées :**
1. **Orthographe/grammaire** : Correction des fautes (*"recceuillir" → "recueillir"*, *"au-près" → "auprès"*, *"testés" → "testé"*, etc.).
2. **Structure** : Ajout de titres clairs et de séparateurs (`---`) pour une meilleure lisibilité.
3. **Mise en forme** :
   - Utilisation de **gras** pour les suggestions importantes.
   - Reformulation des retours pour plus de fluidité.
   - Ajout de sauts de ligne (`<br>`) dans le tableau pour une lecture plus agréable.
4. **Précision** : Ajout de guillemets pour les citations et de notes (*photo 1*, *image 1*).
